# Como inicializar um site utilizando Laravel Herd

# 1 - Instalação

Vá no site do Laravel Herd e faça o download na página inicial ou vá na documentação, e no tópico Installation aperte no texto 'here' em negrito para fazer o download do Setup.

Após isso, execute o setup, next next next e finish.

Inicialize o app que foi instalado, next next e escolha o local em que os sites serão criados.

Após isso o ambiente já deve estar configurado.

# 2 - Criando o site

Aperte na aba 'Sites' do Herd e depois no botão 'Add'.

Na tela que aparecer, escolha 'New Laravel Project'.

Escolha o starter kit (normalmente No Starter Kit ou React).

De um nome ao projeto, escolha o testing framework (Siles gosta mais do PHPUnity). Não escolha a opção 'Initialize a git repository' se você estiver criando o projeto dentro de um repositório. Escolha onde o projeto vai ser criado e aperte Next.

Espere um tempinho e pronto.
